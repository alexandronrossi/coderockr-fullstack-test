Introduction

JSON API for creating, listing, viewing, and withdrawing investments.

Base URL: http://localhost:8000 
This is the HTTP API for the Coderockr investment application. The SPA consumes these JSON endpoints; it is not served by Laravel.

<aside>As you scroll, you'll see code examples in the dark area to the right (or as part of the content on mobile).
You can switch the language with the tabs at the top right (or from the nav menu on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Send a Sanctum Bearer token in the Authorization header. Admin may access every investment; Owner may access only their own. Endpoints that do not require a token are marked as unauthenticated.

Authentication

Sign in

Authenticates with email and password and returns a Sanctum Bearer token. Extra fields such as role or user_id are ignored.

Example request:
curl --request POST \
    "http://localhost:8000/api/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"owner@example.com\",
    \"password\": \"password\"
}"

const url = new URL(
    "http://localhost:8000/api/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "owner@example.com",
    "password": "password"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
$client = new \GuzzleHttp\Client();
$url = 'http://localhost:8000/api/login';
$response = $client->post(
    $url,
    [
        'headers' => [
            'Content-Type' => 'application/json',
            'Accept' => 'application/json',
        ],
        'json' => [
            'email' => 'owner@example.com',
            'password' => 'password',
        ],
    ]
);
$body = $response->getBody();
print_r(json_decode((string) $body));

Example response (200, ok):


{
    "token": "1|plainTextToken",
    "user": {
        "id": 1,
        "name": "Owner",
        "email": "owner@example.com",
        "role": "owner"
    }
}

Example response (401, invalid):


{
    "message": "Invalid credentials."
}

Investments

List investments

requires authentication

Paginated investments visible to the current user. Owners see only their own records. Admins see every owner's investments. Query user_id is ignored.

Example request:
curl --request GET \
    --get "http://localhost:8000/api/investments?page=1&per_page=15" \
    --header "Authorization: Bearer {YOUR_TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"page\": 16,
    \"per_page\": 22
}"

const url = new URL(
    "http://localhost:8000/api/investments"
);

const params = {
    "page": "1",
    "per_page": "15",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Authorization": "Bearer {YOUR_TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "page": 16,
    "per_page": 22
};

fetch(url, {
    method: "GET",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
$client = new \GuzzleHttp\Client();
$url = 'http://localhost:8000/api/investments';
$response = $client->get(
    $url,
    [
        'headers' => [
            'Authorization' => 'Bearer {YOUR_TOKEN}',
            'Content-Type' => 'application/json',
            'Accept' => 'application/json',
        ],
        'query' => [
            'page' => '1',
            'per_page' => '15',
        ],
        'json' => [
            'page' => 16,
            'per_page' => 22,
        ],
    ]
);
$body = $response->getBody();
print_r(json_decode((string) $body));
